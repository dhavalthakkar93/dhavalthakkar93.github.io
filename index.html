Solar Power Equation

Psolar = η(T) × A × GHI × (1 - S)
Psolar = Generated power (Watts)
η (eta) = Panel efficiency at temp T (15-20%)
A = Panel surface area (m²)
GHI = Global Horizontal Irradiance (W/m²) — BH1750
S = Soiling index (0=clean, 1=dirty) — Laser+LDR

Temperature Degradation

η(T) = ηref × [1 - β × (Tpanel - 25°C)]
ηref (eta-ref) = Reference efficiency at 25°C (datasheet)
β (beta) = Temp coefficient (≈0.004/°C for silicon)
Tpanel = Panel surface temp — GY-906 MLX90614
Sensor Roles — Solar

Solar Node — Sensor Deep Dive

Each sensor serves a specific role in the forecasting pipeline

☀️

BH1750 — Light Sensor

Measures luminous intensity in lux (0–65,535). Converted to GHI (W/m²) using calibration factor. GHI is the primary driver of solar power — the single most important input to the model.

Interface: I2C (0x23) • 16-bit digital output • ±20% accuracy
🌡️

BME280 — Environment

3-in-1 sensor: Temperature (-40 to +85°C), Humidity (0-100%), Barometric Pressure (300-1100 hPa). Used for weather context and air density calculation for both nodes.

Interface: I2C (0x76) • ±1°C / ±3% RH / ±1 hPa accuracy
🔥

GY-906 MLX90614 — Panel Temp

Infrared thermometer — measures panel surface temperature without physical contact. Every +1°C above 25°C reduces efficiency by ~0.4%. Critical for temperature degradation modelling.

Interface: I2C (0x5A) • -70 to +380°C range • ±0.5°C accuracy
⚡

ACS712 — Current Sensor

Hall-effect sensor measures DC current flowing from the panel. Combined with known voltage to calculate actual power output (W). Auto-calibrates zero-point at startup.

Interface: Analog (GPIO34) • 0-30A range • 66mV/A sensitivity
🔴

KY-008 Laser + LDR — Soiling

Novel soiling detection: Laser beam bounces off panel surface. Clean panel reflects strongly (high LDR reading). Dust/dirt absorbs light (low reading). Produces soiling index 0-1 for cleaning scheduling.

Laser: Digital (GPIO27) • LDR: Analog (GPIO36) • Calibrated at startup
💻

SH1106 OLED — Display

128x64 pixel OLED shows live readings on the node itself. Useful for field debugging without needing laptop/phone. Displays GHI, temps, power, soiling in real-time.

Interface: I2C (0x3C) • Adafruit SH110X driver • 2s refresh

🔎 Prototype vs Production

Potentiometers simulate anemometer and wind vane. These instruments could not be arranged within a 1-week prototype timeline, but firmware reads the same analog GPIO pins — swapping to production sensors requires zero code changes.

Anemometer: Cup-type rotates with wind, generates Hall-effect pulses ∝ speed.
Wind Vane: Internal resistive pot rotates with wind direction, outputs 0-3.3V → 0-360°.

Wind Power Equation

Pwind = 0.5 × ρ × A × Cp × v3
Pwind = Extracted power (Watts)
ρ (rho) = Air density (kg/m³) — from BME280 pressure & temp
A = Rotor swept area (πr², m²)
Cp = Power coefficient (max 0.593, Betz limit)
v3 = Wind speed cubed — 2x speed = 8x power

Air Density ρ (Real-time from BME280)

ρ = P / (Rspecific × T)
P = Atmospheric pressure (Pa) — BME280
Rspecific = Gas constant for dry air: 287.058 J/(kg·K)
T = Absolute temperature (Kelvin) — BME280
Hot air = lower ρ = less power. Real-time calculation improves accuracy 3-5%.
Sensor Roles — Wind

Wind Node — Sensor Deep Dive

Understanding what each sensor measures and why it matters for forecasting

🌀

Anemometer (Pot Proxy)

Measures wind speed (0–25 m/s). The most critical wind input — power scales with v³, so small speed errors compound dramatically. In production: cup anemometer or ultrasonic sensor.

Analog GPIO34 • 12-bit ADC • Mapped 0–25 m/s linear
🧭

Wind Vane (Pot Proxy)

Measures wind direction (0–360°, mapped to N/NE/E/SE/S/SW/W/NW). Directional data is crucial for turbine yaw control and spatial correlation between plants. In production: magnetic wind vane.

Analog GPIO35 • 12-bit ADC • Mapped 0–360° → 16 compass points
🌡️

BME280 — Atmospheric

Provides pressure + temperature for real-time air density (ρ) computation. Also detects weather fronts (pressure drops) that signal incoming wind pattern changes. Humidity affects turbine blade icing risk.

I2C (0x76) • Pressure: 300-1100 hPa • Temp: -40 to +85°C
💫

MPU-6050 — Vibration

6-axis IMU (accelerometer + gyroscope). We compute vibration RMS from 3-axis acceleration. High vibration indicates bearing wear, blade imbalance, or structural fatigue — enables predictive maintenance.

I2C (0x68) • ±16g range • 16-bit resolution • 1kHz sample rate
VIBRATION FORMULA
vibRMS = √(ax² + ay² + az²)
ax, ay, az = 3-axis acceleration (m/s²)
Normal: < 2.0 • Warning: 2.0–5.0 • Critical: > 5.0

Reliability

Conformal Prediction

Distribution-free uncertainty quantification with guaranteed coverage

How It Works

1. Train model on training set
2. Compute residuals on calibration set
3. Use residual quantiles as prediction intervals
4. Guaranteed coverage regardless of model

Why Not Bayesian?

• No distributional assumptions
• Works with any base model (XGBoost)
• Computationally cheap (no sampling)
• Finite-sample validity guarantee

• Native downsampling (1-min → hourly → daily)
• Handles millions of points from multiple plants
